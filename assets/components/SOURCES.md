# Fuentes de las imágenes de componentes

Las imágenes se han recortado, optimizado a WebP y, cuando era necesario, se ha eliminado el fondo para integrarlas en las tarjetas.

Todos los recortes publicados usan un lienzo transparente común de 720 × 420 px. El contenido visible queda alineado al borde derecho del propio lienzo para que la web pueda ampliarlo sin recentrarlo ni perder nitidez.
